Watch a Cosmos update flow into Azure AI Search

Patch one field on a device, then watch the change-feed trigger upsert new chunks into the index. The middle "Upserting" phase is the merge-first window: old chunks are still searchable while the new ones land, so a failure here never blanks the index.

  1. Cosmos write
    Waiting for an update...
  2. Change feed pending
    No new chunks at the new deviceVersion yet.
  3. Merge-first window (P0-1)
    New chunks present alongside the previous version. The index is never blanked.
  4. Consistent
    Stale chunks deleted. Only the new deviceVersion remains for this source.
